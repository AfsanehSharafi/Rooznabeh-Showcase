# Rooznabeh – Advertising Web Application

A full-stack advertising platform inspired by Divar, built with modern software architecture and clean code principles.

## 🚀 Overview

Rooznabeh is a web application where users can register, log in, post advertisements, search and filter ads, upload images, and manage their own ads. The project is designed to demonstrate real-world software development skills using ASP.NET Core on the backend and React on the frontend.

## 🛠️ Technologies

### Backend
- C#, .NET
- ASP.NET Core Web API
- Clean Architecture
- Domain-Driven Design (DDD)
- CQRS (Command Query Responsibility Segregation)
- REST APIs
- Entity Framework Core
- JWT Authentication
- SQL Server / PostgreSQL

### Frontend
- React
- JavaScript
- HTML5
- CSS3

### Tools & Practices
- Git & GitHub
- Unit Testing (xUnit)
- Dependency Injection
- SOLID Principles

## ✨ Features

- User registration and login (JWT)
- Create, edit, and delete ads
- Upload images for ads
- Search ads by keyword
- Filter ads by category, price, and location
- Responsive UI
- Role-based access (admin/user)

## 🏗️ Architecture

The backend follows Clean Architecture, separating the solution into layers:
- Domain
- Application
- Infrastructure
- Web API

CQRS is used to separate read and write operations, making the system more scalable and maintainable. DDD patterns are applied in the Domain layer to model business logic.
